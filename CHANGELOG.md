# Changelog

All notable changes to this project are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - Unreleased

### Added

- Tab fieldtype that groups the fields after it into tabs in the publish form.
- Support for blueprint sections, Replicator and Bard sets, stacked Grid rows, Groups and nested sets.
- Top and left placement, optional icons, keyboard navigation and `tablist` roles.
- A red marker on tabs that contain validation errors, and the first such tab opens when errors appear.
- Dark theme styles.
- Tab fields are hidden in Grid table mode instead of showing as empty columns.
